# Tesla Fleet API origin

This GitHub Pages site is the allowed origin for a personal Tesla Fleet API app.

- Origin: `https://khandfw.github.io`
- Redirect: `https://khandfw.github.io/callback`
- Public key: `https://khandfw.github.io/.well-known/appspecific/com.tesla.3p.public-key.pem`

The private key is **not** in this repository. Keep `private-key.pem` only on your machine.
